# EarnZone

A responsive React + Vite referral directory showcasing micro-task, survey, crypto earning platforms and mobile apps.

## Features

- Micro-task and earning platforms directory
- Referral links
- Platform cards
- Detailed platform guides
- Payment methods
- Official sources and documentation
- Responsive design

## Technologies

- React
- Vite
- TypeScript

## Project Purpose

EarnZone is a personal referral landing page designed to help visitors discover online earning platforms, understand how they work, and access them through referral links.
